**Penjelasan Singkat :**
Design system adalah kumpulan aturan visual yang dipakai berulang supaya tampilan konsisten. Isinya warna, tipografi, spacing, tombol, form, dan card. Semuanya saya simpan sebagai variabel CSS di bagian atas style.css, lalu didokumentasikan di design-system.html.
> Penerapan ke dashboard:<br>
> - Struktur tidak diubah. Di HTML hanya ada dua perubahan: tombol “Isi KRS” ditambahkan dan teks alt foto diperbaiki.<br>
> - Di CSS, nilai acak diganti token. Ukuran font seperti 13, 14, dan 17px kini mengikuti type scale. Padding dan margin mengikuti skala 4/8px, dan warna mengikuti palet.<br>
> - Hasilnya lebih konsisten dan mudah dirawat. Mengubah warna utama cukup di satu tempat. Hierarki juga lebih jelas, misalnya jam jadwal berwarna primary, header tabel diberi latar, dan ada tombol primary untuk aksi utama.

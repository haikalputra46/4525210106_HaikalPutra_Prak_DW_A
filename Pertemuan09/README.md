### Penjelasan Perubahan Website Dashboard Akademik
1. **Bootstrap 5:** Menggunakan Bootstrap 5 melalui CDN untuk mempermudah pembuatan tampilan website.
2. **Statistic Cards:** Menambahkan empat kartu statistik yang menampilkan Total Mahasiswa, Mahasiswa Aktif, Mahasiswa Cuti, dan Mahasiswa Keluar.
3. **Grid System:** Menggunakan Container, Row, dan Column untuk mengatur tata letak kartu agar lebih terstruktur.
4. **Breakpoint:** Mengatur tampilan kartu agar responsif, yaitu 1 kolom pada HP, 2 kolom pada tablet, dan 4 kolom pada laptop.
5. **Tabel Data:** Menambahkan tabel berisi 10 data mahasiswa dengan informasi NIM, nama, program studi, angkatan, status, dan aksi.
6. **Table Classes:** Menggunakan `table-striped` untuk warna baris bergantian, `table-hover` untuk efek saat kursor diarahkan, dan `table-responsive` agar tabel dapat menyesuaikan layar kecil.
7. **Utility Classes:** Menggunakan class seperti `mt-4`, `mb-3`, dan `p-3` untuk mengatur jarak dan tata letak elemen.
8. **Badge dan Button:** Menambahkan badge berwarna untuk membedakan status mahasiswa serta tombol Tambah Mahasiswa dan Detail.
9. **Footer:** Menambahkan bagian footer yang berisi informasi hak cipta dan nama sistem.
